# Employee Well-Being Web Application 

**Program:** Fintech Focus Program\
**Corporate Sponsor:** Morgan Stanley\
**Language:** Python

## Overview

This project is a curated resource dedicated to empowering employees with practical guidance on improving 
physical, mental, and nutritional well-being. It offers insights into healthy lifestyle practices and serves 
as a central hub for wellness information you can use every day.

## Key Features

The site is desined to make well-being accessible and actionable:
* **Fitness** - Tips and guidance for staying active and maintaining physical health
* **Nutrition** - Evidence based advice on healthy eating and balanced diets
* **Mental Health** - Resources and practices for emotional resilience and stress management
* **Contact & FAQs** - Get in touch or find answers to common wellness questions

## Purpose

Good health extends beyond the absence of illness. It encompasses physical fitness, mental balance, 
and informed lifestyle choices. This site aims to encourage sustainable health habits, provide 
easy-to-understand wellness advice, and inspire employees to take proactive steps toward long-term well-being.

## How to Run

* The site is hosted on GitHub Pages and authored using HTML, CSS, Bootstrap, Python, and Flask.
